# Chidiogo Joy Simon — Portfolio

A single-page portfolio site for **Chidiogo Joy Simon**, Horticulturist, Agronomist, and Greenhouse & Vegetable Production specialist.

## Sections

- **Hero** — introduction and quick stats
- **About** — professional summary and key facts
- **Skills** — core horticultural and agronomic competencies
- **Experience** — career timeline (Manamuz Ltd, Agrivantage, Soiless Farm Lab)
- **Education** — academic background
- **Professional Development** — courses and certifications
- **Training & Facilitation** — community training impact
- **Contact** — direct ways to get in touch

## Tech

Plain HTML, CSS, and vanilla JavaScript — no build step or framework required.

- `index.html` — page structure and content
- `style.css` — styling, palette (dark green / lemon / milk), and responsive layout
- `script.js` — mobile nav toggle, footer year, and scroll-in animation

## Running locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploying

The site is static and can be hosted directly on GitHub Pages:

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select the `main` branch and `/ (root)` folder, then save.

The site will then be live at `https://emiloart.github.io/Chidiogosimon/`.
